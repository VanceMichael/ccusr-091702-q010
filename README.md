# 错峰线路配额协调器

本服务用于多场馆行程、团组容量和缩容改线。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：线路版本、团组、场馆时窗、配额、保障名额、方案占位、调整候选。

多段配额确认全成或全败；缩容只生成候选方案；已经开始的团组不得自动改写；未确认占位到期后释放。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/offpeak_itinerary.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
